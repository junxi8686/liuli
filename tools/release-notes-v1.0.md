琉璃 1.0 —— 第一个可用版本

一个用**蓝牙**聊天的 Android 应用：不用服务器、不用流量、不用账号。
两台手机配对后直接收发文字、图片、视频和语音。

## 权限

**不申请 `INTERNET`。** 已从 APK 实际核对权限列表，里面没有 `android.permission.INTERNET`：
字节只走蓝牙。（`ACCESS_NETWORK_STATE` 是某个依赖库带进来的，它只读网络状态、
不传输任何数据。）

## 这一版验证到什么程度

真机是 Galaxy S24 Ultra / Android 16。

- **协议自检 39/39 全部通过**，跑在设备上。覆盖握手、单聊落库、回执、打字指示、
  1 MB 文件 sha256 校验、群通话扇出与挂断、通话帧抢占写队列，以及离线中转的完整
  链路（A 发出 → B 保管 → A 离线、C 连上 B → C 收到 A 的原消息）。
- **真机双向收发文字**：对方发来的消息正常到达并落库。
- **真机图片收发**：一张真实照片在消息流里正常渲染。
- **通话**：能接通（有通话时长记录），也出现过未接通的情况。
- 单元测试 **121 个全绿**（`app/src/test/`）。

细节和截图见 README 的「验证到什么程度」一节。

## 已知限制

- **传输速度受蓝牙限制**，实测约 100–200 KB/s。一张压缩后的照片约 2 秒，
  一段 30 秒的视频可能要几分钟。发之前会给出预估。
- **视频不转码**（工程里没有 ffmpeg）。超过 50 MB 的视频会被拦下，需要自己先裁。
- **两台设备必须都装有本应用。**
- **没有「拉黑」功能，这是刻意的。** 早期做过一版，但「配对即好友」之后它绕得过去：
  对方在系统蓝牙里解除配对再重新配对，就又成了好友。一个绕得过去的开关比没有更糟。
  真正有效的手段是解除配对，所以「删除好友」会把人送到系统蓝牙设置。
- **离线中转不是端到端加密的**：替别人保管消息的中间设备在转发前能看到明文。
  能保证的只是：不显示、不落库、确认送达后删除、缓存有上限。
- **群信息页的群管理入口（公告 / 禁言 / 管理员 / 转让群主 / 踢人）没有在真机上打开过。**
  代码和接口都完成、编译通过，但那一屏缺少实机验证。
- **平板双栏**（宽度 ≥ 720dp 时左列表 + 右内容）代码完成、编译通过，
  同样没有实机截图验证。
